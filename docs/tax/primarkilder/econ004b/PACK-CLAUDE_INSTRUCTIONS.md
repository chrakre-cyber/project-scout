# Oppdrag: les tilleggskildene og avklar påstander

Kontroller MANIFEST.json og ACQUISITION.json. Les HTML-originalene, bruk TXT bare som lesestøtte. Registrer dokumentidentitet, hash, proveniens og dekkede påstander uten å løfte hele regler på grunnlag av delvis belegg. Gjenbruk eksisterende kilde-ID der relevant.

1. Les særavgiftsloven LOV-2026-06-19-41 §§ 26-1 og 26-2. Skill lovens identitet, materielle endringer og ikraftsetting. En kunngjort lov med «Kongen bestemmer» er ikke alene bevis for at ingen senere ikraftsetting har skjedd. Oppgi konkret relevans for de aktuelle ECON-004-reglene; ikke viderefør lovnummeret som en generell blokkering.
2. Les LOV-2025-12-22-121 del I og III og Prop. 1 LS punkt 11.2.5. Avklar hva overgangsregelen faktisk omfatter. Ikke gjør en leasingovergang til et generelt importunntak. Forslag/varsler om 2027/2028 er ikke vedtatte regler.
3. Undersøk om punkt 11.2 faktisk avgjør elbilgrensens målegrunnlag ved innførsel. Hvis ikke, si presist hva som fortsatt mangler; ikke velg mellom tollverdi og kjøretøypris på grunnlag av produktpreferanse.
4. Les deklarasjonsveiledningens rubrikk 22/23, 45/46/47. Skill privat/ikke-registrert import fra mva-registrerte virksomheters rapportering. Avstem formuleringen om fri rådighet med gjeldende lov/forskrift om akseptdato. Registrer eventuell terminologisk spenning uten å endre koden.
5. Les mva-FAQens spørsmål om aggregeringsnivå og desimalkutt. Ikke oppgrader en valideringstoleranse til en avrundingsregel. Sammenhold med de allerede arkiverte skattebetalingskildene, og skill samlet avgiftskrav fra hver deklarasjon og mva-meldingens linjer. Ikke endre ECON-003-literalene eller innfør floor per import på dette grunnlaget.
6. Lever en kort oppdatert kildevurdering: besvarte delspørsmål, gjenstående presise spørsmål og forslag til registerendringer. Ingen nye kodeendringer, produktvalg eller parametergodkjenninger i denne runden.

ECON-004 forblir REVIEW. Økonomiflaggene forblir false. ECON-002 er uendret. ECON-005 skal ikke startes.
